# Правила за Claude в това репо

## Език
- Потребителят **не разбира английски**. Всичко, което му пишеш (отчети, въпроси, резюмета, грешки), е **само на български**.
- Всички текстове в играта са на български. Кодът, имената на файлове и коментарите в кода може да са на английски.

## Публично репо — нищо лично
Репото е **публично** (GitHub Pages). Никога не качвай:
- пътища от компютъра (`C:\Users\...`), потребителски имена, имейли;
- местоположение на автора (село, град) — нито в играта, нито в README, нито в описания;
- бележки за сесии (`SESSION_NOTES.md` е в `.gitignore` и остава само локално), ключове, пароли, токени.
Имената в играта („Самодивско“ и т.н.) са измислени — не ги свързвай с реални места.

## Как работиш
- Работиш **сам, без да питаш** — потребителят спи или е на работа. Където трябва решение, вземи разумното и го запиши в `PLAN.md` → раздел „Решения“.
- Малки commit-и често (след всяка завършена стъпка), съобщенията на commit-ите — на български.
- Push в `main`. Ако средата не позволява push в `main`, push в своя клон и отвори PR към `main` с описание на български.
- Не пипай `.github/workflows/` без нужда — двата workflow-а (Pages и Windows .exe) вече са готови и чакат `package.json`, `npm run build` → `dist/` и `desktop/build.mjs`.
- Преди край: `npm run check` и `npm run build` трябва да минават. После обнови `PLAN.md` (какво е готово ✔, какво остава) и `README.md`.
- Последното ти съобщение в сесията: кратък отчет **на български** — какво е готово, линк към играта, как се играе, какво следва.

## Технологии (като в публичното репо https://github.com/me7ko-dev/orda — ползвай го за пример)
- Vite + TypeScript + three.js, `base: './'` във `vite.config.ts`.
- Windows `.exe`: Electron както в orda (`desktop/main.cjs` с вътрешен сървър на `127.0.0.1`, `desktop/build.mjs`, който само преименува `electron.exe` — без подписване и промени по exe-то).
- Сглобяването на `.exe` е само в GitHub Actions, не на лаптопа на потребителя.
- Без сървъри и без платени услуги. ИИ на жителите е **локален** (Ollama на компютъра на играча) с резервен „мозък по сценарий“.

Подробният план е в `PLAN.md` — прочети го целия преди да започнеш.
