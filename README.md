# Балкански легенди — живото ИИ село

3D ролева игра в свят от българските митове: Ламята, самодивите, таласъмите и Караконджулът. Жителите на селото са **живи ИИ герои** с характер, памет и тайни. Говорят си, клюкарстват, карат се и сами си избират кмет. Всичко се записва в летопис, а с машината на времето можеш да върнеш света назад.

- Репо: https://github.com/me7ko-dev/Ai-selo
- Играта в браузъра: https://me7ko-dev.github.io/Ai-selo/ (появява се след първата версия)
- За Windows: [Releases → latest](https://github.com/me7ko-dev/Ai-selo/releases/tag/latest) → свали zip-а, разархивирай и пусни `.exe`-то

Планът е в [PLAN.md](PLAN.md).

## Как се пуска
**В браузъра:** отвори линка горе. Там жителите говорят по сценарий.

**С живи ИИ жители (на твоя компютър):**
1. Инсталирай [Ollama](https://ollama.com) и свали малък модел, например `ollama pull qwen3.5:4b`.
2. Пусни Windows версията (`.exe`). Тя сама намира Ollama.

**За разработка:** `npm install`, после `npm run dev`.
